# Dataset Directory

Organize the original images into class directories:

```text
dataSets/Jujube12000/
├── bianxing/
├── gantiao/
├── haozao/
├── liekou/
├── meibian/
└── niaozhuo/
```

The code does not move or copy the original images. Training, validation, and test splits are stored in `splits/`.
